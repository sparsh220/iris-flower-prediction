# Iris Flower Prediction

## About the Project
This project predicts the species of an Iris flower using four measurements.

## Technologies Used
- Python
- Pandas and Scikit-learn
- Flask
- HTML and CSS
- GitHub and Render

## Machine Learning Model
I trained a Random Forest Classifier to predict one of three species:
- Setosa
- Versicolor
- Virginica

## How to Use
1. Open the web application.
2. Enter the four flower measurements.
3. Click the Predict Species button.
4. View the predicted species.
